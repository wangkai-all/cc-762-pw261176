# CurveLab — 缺测日内曲线的函数型建模与稳健聚类

把虚构站点的日内需求观测视为周期域 \[0, 24h) 上的**完整函数**，而不是长度固定、
缺测填零的向量。缺测段在平滑约束下重建，并把**重建不确定性传播到距离与聚类判断**；
相位偏移与峰高变化分开解释；证据不足的日子保持"未定"而不是被硬塞进某类。

## 为什么不能"缺测填零 + 普通向量聚类"

填零把"没观测"伪装成"真实的零需求段"：

- 缺口位置不同的两天会因零值位置不同而产生巨大欧氏距离，哪怕真实曲线几乎相同；
- 缺口越长，距离越被缺口主导，真实峰型信号被淹没。

`tests/test_curve_lab.py::test_fillzero_would_mislead` 是对照实验：
同一原型、缺口位置错开的两天，填零法把它们排得比异原型还远；本工具的函数型距离
保持正确的远近次序。

## 方法链路

| 环节 | 文件 | 做法 |
|---|---|---|
| 基函数表示 | `curve_lab/basis.py` | 周期三次 B 样条（边界天然连续，缺测不确定性保持局部） |
| 平滑拟合 | `curve_lab/fitting.py` | 惩罚最小二乘，GCV 自动选 λ；后验协方差给出逐点重建方差 |
| 峰型识别 | `curve_lab/features.py` | 周期峰值检测：单峰/双峰/错峰/平缓，峰位、峰高、prominence |
| 时间扭曲 | `curve_lab/warping.py` | 斜率有界 DP（COW 风格）+ 可选抛光；s_max 限制不合理拉伸 |
| 函数型距离 | `curve_lab/distance.py` | 方差项进入距离；拆成形状/峰高/相位三个可解释分量 |
| 聚类与弃权 | `curve_lab/cluster.py` | k-medoids（medoid 是真实日）+ 异常阈值 + "未定"规则 |
| 增量基线 | `curve_lab/pipeline.py` | medoid/阈值冻结；仅明确重建日可移动功能均值中心，全程留痕 |
| 数据接入 | `curve_lab/dataio.py` | 长表 CSV 与 JSON；缺测直接缺行 |
| Web 后端 | `curve_lab/app.py` | 标准库 `http.server`，无第三方 Web 框架 |
| 前端 | `web/` | 原生 SVG/JS，无构建步骤 |

### 不确定性如何进入距离

对拟合曲线 f、g（后验均值 μ、标准差 σ）：

```
E‖f−g‖² = ∫ (μ_f−μ_g)² dt + ∫ (σ_f² + σ_g²) dt
```

缺测区 σ 自动升高，因此"看不准"的区间在距离里被如实惩罚，而不是被当作零值。

### "未定"与"异常"是两回事

- **anomaly**：证据充分，但到所有基线类的距离都超过训练分布上稳健标定的阈值；
- **undetermined**：证据不足（观测点过少、最长缺测超限、重建不确定性超训练分位数，
  或最近两类距离差过小）。这类日不参与类中心更新。

### 基线冻结规则

1. 训练日拟合、配对距离、k-medoids、阈值标定一次完成后冻结 medoid 与阈值；
2. 新日期只对照冻结基线评分，不触发重新聚类；
3. 只有状态为 `cluster` 且非人工排除的新日才能更新该类的**功能均值中心**，
   medoid 与阈值永不移动，每次更新记录 RMS 位移；
4. 人工排除日保留全部原始观测与拟合结果，仅不参与中心更新，可在界面对比；
5. 界面调参（λ、s_max、k、基函数数）会显式"重建基线"，是一次可追溯的新基线，
   而非悄悄移动历史判定。

## 快速开始

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 命令行：内置虚构站点全流程，并导出 JSON 报告
.venv/bin/python -m scripts.run_demo

# 生成样例 CSV（缺测时刻直接缺行），再从文件接入
.venv/bin/python -m scripts.run_demo --emit-csv data/sample.csv
.venv/bin/python -m scripts.run_demo --input data/sample.csv

# 网页
.venv/bin/python -m curve_lab.app        # http://127.0.0.1:8000
```

## 网页功能

- **叠加曲线**：按类/状态着色叠加全部训练日与新日，可叠加类中心；
- **单日重建**：重建曲线 + 95% 后验带 + 原始观测点，缺测段阴影标出；
  横向拖动十字线查看任意时刻的重建值、置信区间与后验 SD；
- **两日对齐**：两条曲线对比，右侧面板给出形状/峰高/相位/不确定性距离分解、
  有向相位（提前/滞后小时数）与扭曲实际达到的最大拉伸；
- **参数调整**：平滑 λ（GCV 自动或手动）、最大时间拉伸 s_max、聚类数 k、
  基函数数、缺测判定半径，一键重建并重新冻结基线；
- **内置样例**：双峰、错峰、长缺口、极端峰、稀疏未定日，一键加入并对照基线评分；
- **数据接入**：上传 CSV/JSON，新日自动评分；
- **人工排除**：单日面板按钮切换，数据始终保留。

## 数据格式

CSV（时间单位小时，取值 \[0, 24)）：

```csv
day_id,time,value
2026-11-01,0.5,12.3
2026-11-01,1.0,11.8
```

JSON：

```json
{"days": [{"day_id": "d1", "times": [0.5, 1.0], "values": [12.3, 11.8]}]}
```

缺测无需也不应填零——对应时刻直接缺行。

## 测试

```bash
.venv/bin/python -m unittest tests.test_curve_lab -v
```

覆盖：基函数周期性与单位分解、已知曲线重建精度、缺测不塌零、GCV/手动 λ、
扭曲相位恢复与斜率约束、距离的相位/峰高分离与不确定性传播、填零对照实验、
聚类原型恢复与确定性、异常/弃权判定、基线冻结与中心更新门控、排除日数据保留。
